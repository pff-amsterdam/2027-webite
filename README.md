# PFFA 2027

Single-page "coming soon" site for Porn Film Festival Amsterdam 2027 — a hero
photo with the festival title and three submission links (films,
performances, workshops).

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run dev
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```

## Hero image

Drop the background photo in as `public/hero-background.jpg`. See
`public/README-hero-image.txt` for details. The page falls back to a solid
navy background until that file is added.
